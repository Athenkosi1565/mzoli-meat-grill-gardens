# Mzoli Meat, Grill & Gardens

Production-ready Next.js website for **Mzoli Meat, Grill & Gardens**, 15 Barnet Street, Gardens, Cape Town, 8001.

Stack: Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Lucide · optional Supabase.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open http://localhost:3000
